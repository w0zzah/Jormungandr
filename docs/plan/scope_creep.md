## Concept: Complete the function first
### Tags: PVP, Competitive, Conflict, Goal Orientated
First to write a function that can do 'x' wins 
The file has max 1000 lines. Each day the user can login and write a line to finish the function x
They can pick a number between 1-1000, and the number they pick lands them -10 and +10 from that point (e.g I pick 676, I can see lines 676-686)
They can either choose to start writing their function or if they find someone elses, they can change theirs.
